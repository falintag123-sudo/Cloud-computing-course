Cloud Concepts Reflection

I use many cloud services every day for school and personal use. Three cloud services I use the most are Google Drive, Canva, and Messenger. These apps help me finish my school work and stay connected with other people.

Google Drive is an example of Software as a Service (SaaS). I use it to save my files, pictures, and school documents online. I do not need to bring a USB because I can open my files from different devices with an internet connection. I also use it to share files with my classmates and teachers. Google Drive uses a public cloud because many people around the world use it through the internet.

Canva is also a Software as a Service (SaaS). I use Canva to make presentations, posters, and other school projects. It is easy to use because it has many ready-made templates. My work is saved online, so I can continue it on another phone or computer. Canva also uses the public cloud because it is open to anyone with an internet connection.

Messenger is another Software as a Service (SaaS). I use it every day to chat with my classmates, friends, and teachers. It helps me ask questions about assignments and receive updates from school. My messages, photos, and videos are stored online, so I can see them on different devices. Messenger also uses the public cloud.

Git and GitHub are useful for school projects, especially when working with other people. Git keeps track of every change made to a project. If someone makes a mistake, it is easier to go back to an older version. GitHub lets team members work on the same project without replacing each other's work. It also shows who made each change, so the project stays organized.

After learning about cloud computing, I understand that many apps I use every day depend on cloud services. I also learned that version control is important because it helps keep files safe, organized, and updated. It also makes teamwork easier because everyone can work together on the same project. This activity helped me understand how cloud computing is useful in school, in daily life, and in future work.
